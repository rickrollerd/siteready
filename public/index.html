          Job steps

          Ticked steps go into the SWMS. SiteWrite ticks the ones it found in the task. Untick any that are not part of this job, and add any that are missing. Steps marked recommended are called for by the task's words; if you untick one, make sure that risk is covered another way.

            Facts

            Personal protective equipment

            Ticked items are suggested for this task. Some are worn for all work; others only in the steps that need them, such as a face shield while grinding. Change them to suit the job and the site rules.

            Site-specific

            Answer each one for this site. They are needed before download. Where there truly is none, write None (Access always needs an answer).

            Designs this work relies on

            Some job steps here are done to an engineer's or temporary works design. A reviewer checks your SWMS matches that design, so name each one. It prints in the steps that use it, and in a table near the top of the SWMS. Needed before download.

            For example a geotechnical report or a crane pad design.

            Written methodologies and sequences of works

            Optional. Each prints in a table near the top of the SWMS. SiteWrite can read a typed one and suggest job steps for you to check and accept.

            For example the lift company's methodology for raising a jump lift's machine platform.
